# 🧑‍💻 Day 1: Exploring a Simple Agent Loop in Python

This project demonstrates a **minimal agent loop** written entirely in Python without external frameworks. It shows how an agent can take user input, decide if a tool should be called, and return the result.

---

## 🚀 What You’ll Learn
- How to define **tools** (functions like `get_weather` and `get_time`).
- How to describe tools in a simple **spec dictionary**.
- How to build an **agent loop** that:
  - Reads user input.
  - Matches keywords to tools.
  - Calls the right function.
  - Returns the result.
- How to run an **interactive REPL** (read–eval–print loop).

---

## 📦 Requirements
- Python 3.12 or later (tested with Python 3.13).
- No external dependencies — just the Python standard library.
